## 1. Что это за система

Внутренняя CRM компании модульных домов (Django + Postgres + Redis + Daphne + Docker).

Цикл сделки: лид → расчёт → согласования → проектирование → производство → монтаж. Рядом — чат Умника (архив планировок PDF), кабинет заказчика, Telegram-диспетчерская.

С осени 2026 добавлен **мессенджер сотрудников** (`/app/`): PWA «как приложение» на iPhone/Android, в духе Telegram / MAX, с Умником в чатах.

## 2. Что работает сейчас (можно пользоваться)

### 2.1. CRM в браузере

- Вход сотрудников логин/пароль (`/accounts/login/`).
- С телефона после входа редирект в `/app/` (комнаты), с компьютера — на Главную.
- Главная, сделки, задачи, клиенты, сервис, файлы, архив планировок, настройки (для руководства).
- Карточка сделки: конфигуратор, цены, ванные, доп. опции, согласования, разделы проекта, файлы, сообщения клиента, чат Умника на карточке.
- Роли: менеджер, проектировщик, производство, админ, руководитель, скрытый superadmin (владелец).
- Кабинет заказчика: вход по **ID + пароль**, без почты и OTP.

### 2.2. Мессенджер `/app/` (PWA)

Живой адрес: [https://227info.online/app/](https://227info.online/app/)

**Телефон (Safari / Chrome, иконка на Домой):**

- Снизу вкладки: **Контакты**, **Звонки**, **Чаты**, **Настройки**.
- В чатах сверху фильтры: **Все**, **Новые**, **Рабочая** (без сделки), **Клиенты** (есть сделка).
- Контакты с кружками-инициалами; тап открывает личный чат.
- Можно добавить **Умника** в чат (личный или общий).
- Внизу чата: **+** (файлы), поле текста, **микрофон** (голосовое), отправка.
- Голосовые пишутся в браузере (Safari спросит микрофон) и уходят вложением.
- Установка: Safari → Поделиться → На экран Домой / Open as Web App. Инструкция: `/app/settings/` → «На экран Домой».

**Широкий экран:**

- Слева узкая колонка разделов (как веб-Telegram / MAX).
- Рядом список чатов, справа переписка.
- Колесо мыши крутит ленту сообщений.

**Прокрутка на телефоне:** горизонтальный сдвиг при свайпе ленты убран (`pan-y` + `overflow-x: hidden`).

Тот же мессенджер доступен из CRM: пункт «Комнаты» (`/rooms/`) — упрощённый вид внутри обычного навбара, без нижней панели PWA.

### 2.3. Умник в комнатах

- В чате только с Умником каждое сообщение и файл уходят ему (ответ в фоне, отправка **не** ждёт 180 секунд).
- В общем чате Умник отвечает, если сообщение начинается с «умник, …» / «umnik», или если прислали файл/голосовое без текста.
- Голосовые **расшифровываются** (faster-whisper в контейнере CRM, как в Telegram-боте) и текст отдаётся Умнику. Он должен отвечать по смыслу речи, а не игнорировать «немой» файл.
- Файлы из чата Умник может разложить по сделке (если хватает прав `umnik_capabilities` / `can_attach_design_files`).
- Чат Умника на карточке сделки в десктоп-CRM по-прежнему работает отдельно (`templates/includes/umnik_chat.html`).

### 2.4. HTTPS и телефон

- Домен **227info.online** (и `www`) → VPS, сертификат Let’s Encrypt через **Caddy**.
- Caddy: HTTP/1.1 + HTTP/2 + HTTP/3 (UDP 443), gzip статики, длинный кэш `/static/`.
- Иконка приложения: логотип Country House (`static/img/apple-touch-icon.png`).
- `ALLOWED_HOSTS` / `CSRF_TRUSTED_ORIGINS` включают домен.

**DNS:** публичные резолверы (8.8.8.8, 1.1.1.1) отдают `91.224.86.10`. Часть домашних провайдеров ещё может держать старый IP `95.163.244.138` (сайт там не отвечает) — тогда Safari чёрный экран. Обход: мобильный интернет или `http://91.224.86.10:9090/app/`.

### 2.5. Умник-архив и Telegram

- Облачный query-умник на хосте VPS (`UMNIK_URL`, порт 7861): поиск планировок, чат, правки CRM по протоколу.
- Офисный ПК с `D:\Общая_Рабочая` — только индексатор, не отвечает CRM.
- Telegram-бот диспетчерской: текст, файлы, голосовые с расшифровкой (на проде контейнер `telegram_bot` иногда падал — проверить `docker compose ps`).

## 4. Как устроено на сервере

```
Интернет → Caddy :443 (HTTPS, HTTP/2/3)
              ↓
         Django/Daphne :8000  (контейнер chcrm_app, volume репозитория)
              ↓
         Postgres + Redis

Умник query :7861 на хосте VPS (не внутри compose CRM)
Офис: indexer → снимок индекса (S3 / папка)
```

Полезные команды на VPS (`/home/admin/ch-crm`):

```bash
docker compose --profile https up -d
docker compose restart app
docker compose --profile https logs -f caddy app
```

Статика: при старте `app` делает `collectstatic`. Caddy отдаёт `/static/` из `./staticfiles`.

- Индикатор «Умник печатает…» / статус расшифровки голосового в пузыре.

## 6. Известные ограничения (не баги «на потом», а факты)

- Ответ Умника на голосовое занимает время (STT + модель). Сообщение уходит сразу, ответ догоняет опросом каждые ~2.5 с.
- iPhone кэширует иконку PWA: после смены логотипа ярлык нужно **удалить и добавить снова**.
- HTTP/3 на iOS капризный: если снова чёрный экран при запуске — закрыть Safari с жеста и открыть с LTE.
- Клиентские PDF/фото в `crm_files/` на диск сервера кладутся, в git их не тащим.

## 7. Быстрый чеклист «всё живое?»

1. [https://227info.online/accounts/login/](https://227info.online/accounts/login/) открывается.
2. С телефона вход → список чатов, внизу 4 вкладки.
3. Чат с Умником: поле ввода, **+**, микрофон видны внизу, не под экраном.
4. Текст уходит сразу; Умник отвечает без минуты зависания кнопки.
5. Голосовое: разрешение микрофона → расшифровка → ответ Умника.
6. Файл в чате с Умником не блокирует UI.
7. На десктопе `/app/` — колонка слева, лента крутится колесом.
8. На iPhone лента не уезжает влево-вправо.
