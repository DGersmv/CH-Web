Поставить на телефон

Это сайт, который ставится иконкой. Отдельная программа из магазина не нужна. Вход — тем же логином CRM.

iPhone

  1. Откройте в Safari (не Chrome): https://227info.online/app/
  2. Войдите логином CRM, если ещё не вошли.
  3. Кнопка «Поделиться» (квадрат со стрелкой).
  4. Если есть Open as Web App / «Открыть как веб-приложение» — нажмите и оставьте так. Иконка появится на экране Домой.
  5. Если такого пункта нет: «На экран „Домой“» → Добавить.

Дальше открывайте с иконки, не из вкладок Safari — иначе снова будет обычный браузер.

Android

  1. Откройте https://227info.online/app/ в Chrome.
  2. Меню → Установить приложение (или «На экран Домой»).

Нужен Safari и HTTPS. Сайт уже на https://227info.online.
